# Contributing to Infinit-Null

First off, thank you for considering contributing to Infinit-Null!

## How Can I Contribute?

### Reporting Bugs

* Use a clear and descriptive title
* Describe the exact steps to reproduce
* Include your environment (OS, Go version, etc.)

### Suggesting Enhancements

* Use a clear and descriptive title
* Provide step-by-step description
* Explain why this enhancement would be useful

### Pull Requests

* Follow the Go styleguides
* Include appropriate test cases
* Document new code with comments

## Styleguides

### Git Commit Messages

* Use present tense ("Add feature" not "Added feature")
* Use imperative mood
* Limit first line to 72 characters

### Go Styleguide

* Follow Effective Go
* Use `gofmt` to format code
* Use `go vet` to find errors

### Security Guidelines

* Never commit sensitive data
* Use environment variables for configuration
* Follow OWASP guidelines
* Implement proper authentication
